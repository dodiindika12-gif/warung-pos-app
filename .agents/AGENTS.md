# Aturan Upload GitHub (Versioning)

- Setiap kali ada permintaan untuk "upload ke github" atau melakukan commit/push, tingkatkan versi rilis aplikasi dengan pola `1.X` (misal: saat ini 1.0, berikutnya 1.1, lalu 1.2, dst).
- Tuliskan/Update dokumen `README.md` dengan menambahkan versi terbaru di bagian atas atau log perubahan (Changelog). 
- Catat secara rinci apa saja fitur setiap versinya yang berubah, bertambah, maupun yang dihilangkan.
- Lakukan hal ini secara otomatis sebagai kebiasaan pada saat push ke github.
